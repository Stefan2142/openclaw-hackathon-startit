<task type="auto">
  <name>Task 2: Create claim state JSON schema</name>
  <files>shared/schemas/claim.schema.json</files>
  <action>
Create the complete JSON Schema (draft-07) for the claim state file that all agents read and write.

**Schema sections:**

1. **Root fields:**
   - `claim_id` (string, pattern: "CLM-YYYY-NNNNN")
   - `status` (enum: FNOL_RECEIVED, COVERAGE_CHECKED, ASSESSED, FRAUD_ANALYZED, REVIEWED, PAYMENT_ISSUED, DENIED, ESCALATED, ERROR)
   - `submitted_at` (string, format: date-time)
   - `updated_at` (string, format: date-time)

2. **Claimant section:**
   - `policy_id`, `name`, `contact_phone`, `contact_email`

3. **Incident section:**
   - `date`, `time`, `location`, `description`, `type` (enum: collision, comprehensive, liability, theft, vandalism, weather)
   - `other_party` object (name, insurance_company, policy_number, contact)
   - `police_report_number`, `photos` (array of file path strings)
   - `injuries_reported` (boolean), `witnesses` (array)

4. **Pipeline sections** (one per agent):
   - `front_desk`: completed_at, agent_session, category, priority, cat_event, missing_info[]
   - `claims_officer`: completed_at, agent_session, covered (boolean), policy_status, coverage_type, deductible_amount, coverage_limit, exclusions_checked[], denial_reason, um_uim_route
   - `assessor`: completed_at, agent_session, repair_estimate_usd, total_loss (boolean), acv_usd, salvage_value_usd, parts_recommendation (enum: OEM, aftermarket), labor_hours, rental_days, pre_existing_damage_flags[], hidden_damage_likely (boolean)
   - `fraud_analyst`: completed_at, agent_session, risk_score (0-100), risk_level (enum: low, medium, high, critical), flags[] (array of {pattern, description, severity}), soft_fraud (boolean), recommendation (enum: CLEAR, INVESTIGATE, REFER_SIU)
   - `senior_reviewer`: completed_at, agent_session, decision (enum: APPROVED, DENIED, CONDITIONAL, ESCALATE_HUMAN), decision_reasoning, conditions[], escalated_to_human (boolean), escalation_reason, fcsp_timeline_check object
   - `finance`: completed_at, agent_session, payment_amount_usd, deductible_applied_usd, depreciation_applied_usd, subrogation_candidate (boolean), subrogation_target, payment_method, payment_reference, supplement_eligible (boolean)

5. **Audit log** (array of objects):
   - Each entry: timestamp, agent, action, reasoning, regulation_reference (optional)

**Format notes:**
- Use JSON Schema draft-07
- Include descriptions on every field for self-documentation
- Mark required fields appropriately
- The schema serves as documentation AND validation

**This schema is the contract between all agents.** Every field name here is exactly what agents will read/write in their AGENTS.md instructions (Phase 3).
